# SIDO App (`app_sido`)

Aplicación multiplataforma (**Web, Android e iOS**) del **Sistema Inteligente de Detección de Ofertas (SIDO v2.0)** construida con Flutter y Clean Architecture.

## Propósito
- Mostrar el feed de ofertas reales validadas contra el historial de precios.
- Visualizar gráficas históricas (precio actual vs mediana de 90 días y mínimo de 180 días).
- Exponer el panel de transparencia de **Ofertas rechazadas y por qué**.
- Gestionar listas de seguimiento (*watchlist*), preferencias de categorías y notificaciones push.
